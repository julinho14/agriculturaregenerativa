## 🎯 Sobre o Projeto

**RAIZ Regenera** é uma landing page de alto impacto que apresenta um **nicho bem definido**: a agricultura regenerativa como o caminho **mais lucrativo** para o produtor rural, não apenas o mais sustentável.

O projeto desafia o paradigma de que produtividade e meio ambiente são opostos, mostrando com dados, casos reais e simulações interativas que o equilíbrio gera **mais rentabilidade**.

### 🧠 Conceito Central
> *"O modelo de produção que esgota o solo não é 'forte' — é frágil. A verdadeira força vem do equilíbrio dinâmico."*

---

## 📊 Nicho e Público-alvo

| Público | Por que se importa |
|---------|-------------------|
| **Produtores rurais** (médio/grande porte) | Querem aumentar margem líquida sem destruir o ativo (solo) |
| **Gestores de fazendas** | Buscam reduzir custos com insumos e energia |
| **Investidores do agro** | Procuram ativos com retorno financeiro E ambiental |
| **Cooperativas** | Precisam de cases para convencer associados |

### Diferencial competitivo
- ❌ **Não é** discurso genérico de "salve o planeta"
- ✅ **É** ROI comprovado, dados da Embrapa, simulação financeira

---

## 🚀 Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 📈 **Simulação interativa** | Calculadora conceitual que mostra diferença brutal entre modelo convencional e regenerativo |
| 🔥 **Cases reais** | 3 produtores que aumentaram lucro entre +82% e +217% |
| 📊 **Contadores animados** | Estatísticas que ganham vida ao rolar a página |
| 🌿 **Barra de carbono** | Visualização do sequestro de CO₂ por hectare |
| 🧭 **Navegação suave** | Scroll fluido entre seções temáticas |
| 📱 **Responsividade completa** | Funciona em desktop, tablet e mobile |
